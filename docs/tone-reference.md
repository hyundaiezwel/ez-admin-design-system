## 한계부터

Figma MCP 인증이 안 된 세션이라 파일에서 값을 뽑지 못했다. 캔버스 픽셀 읽기도 막혀 있다
(`preserveDrawingBuffer` 없음 — 중간에 검정값이 나온 건 실제 색이 아니라 빈 버퍼였다).

**아래 hex는 렌더 화면을 눈으로 읽은 근사치다.** 정확한 값이 필요하면 Figma MCP 인증이나
`.fig` 내보내기가 필요하다. 다만 **채택한 것은 값이 아니라 구조**라 이 한계가 결론을 바꾸지 않는다.

canvas를 `ctrl+wheel`로 제어해 Overview · Statistics · Transactions 프레임을 174%까지 확대해 봤다.

## 이 킷의 톤을 만드는 것 다섯

1. **강조색이 하나뿐이다.** 차분한 teal(≈`#2E8B7F`) 하나가 활성 메뉴·CTA·차트·게이지를 다 끈다.
   의미색(빨강·주황)이 화면에 거의 없다 — "Complete" 같은 상태도 뱃지가 아니라 본문색 텍스트다.
2. **차트가 두 색이다.** 주간 비교 막대가 `teal(이번 주) + light gray(지난 주)` 쌍. 게이지도
   teal 호 + 회색 트랙.
3. **숫자가 주인공이다.** `$240,399`가 28~36px bold로 카드를 지배하고 라벨은 12~13px muted로 물러난다.
4. **테두리 대신 여백.** 카드에 보더가 거의 없고 흰 면 + 약한 그림자 + 넉넉한 간격
   (내부 ~24px, 카드 간 ~24px). radius가 크다 — 카드 12~16, 버튼 8~10, pill은 full.
5. **다크 셸 + 밝은 본문.** 사이드바만 near-black, 활성 항목에 teal pill.

## 우리와의 대비 (분석 시점 = @ezwel/ui v1.2.0)

| | Finebank | 당시 우리 |
|---|---|---|
| 강조색 | teal 1색 | teal 1색 ✓ |
| 차트 색 | **2색** | 6색 |
| 본문 | 14px | 13px |
| 큰 숫자 | 28~36px | 24px |
| 카드 radius | 12~16 | 12 |
| 카드 padding | ~24 | 16 |
| 카드 분리 | 여백 + 그림자 | 1px 테두리 |
| 사이드바 | 다크 | 라이트 |
| 정보 밀도 | 낮음 | 높음 |

**색 계열은 이미 같았다. 벌어지는 건 밀도와 위계지 색이 아니다.**

## 기각 — 가져오지 않은 것

**밀도를 전역으로 적용하는 것.** Finebank는 위젯 6~8개짜리 대시보드다. 우리 주문·정산은
30만 행 그리드다. 행 높이를 56px로 올리면 한 화면에 여덟 줄이 들어간다.
→ 밀도를 **토큰 스위치**로 만들어 화면 성격별로 갈랐다.

**muted 텍스트 밝기.** 이 킷의 보조 텍스트와 차트 회색은 우리 4.5:1 / 3:1 기준을 통과하지
못한다. **톤만 가져오고 값은 우리 스케일에서 뽑았다**(`--ez-chart-muted` = gray-40 = 3:1).
여기는 타협하지 않았다.

**본문 14px.** 업무 화면 정보밀도와 상충한다. 13px 유지.
